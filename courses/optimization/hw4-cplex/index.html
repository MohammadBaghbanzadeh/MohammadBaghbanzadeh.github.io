# بخش الف: توضیح مسائل

## 1. مسئله رنگ‌آمیزی گراف (Graph Coloring Problem)

### تعریف مسئله

مسئله رنگ‌آمیزی گراف یکی از مسائل کلاسیک در نظریه گراف و بهینه‌سازی ترکیبیاتی است.

**ورودی:**
- گراف $G = (V, E)$ با مجموعه راس‌ها $V$ و یال‌ها $E$

**هدف:**
- تخصیص رنگ به هر راس به گونه‌ای که:
  1. هیچ دو راس مجاور (متصل با یال) رنگ یکسان نداشته باشند
  2. تعداد رنگ‌های استفاده شده حداقل باشد

**فرمول‌بندی ریاضی:**

$$\text{minimize} \quad k$$

$$\text{subject to} \quad c_i \neq c_j \quad \forall (i,j) \in E$$

$$c_i \in \{1, 2, \ldots, k\} \quad \forall i \in V$$

### کاربردها

1. **زمان‌بندی امتحانات:** دانشجویانی که در دو درس مشترک هستند نمی‌توانند امتحان همزمان داشته باشند
2. **تخصیص فرکانس:** در شبکه‌های بی‌سیم، ایستگاه‌های نزدیک نباید فرکانس یکسان داشته باشند
3. **رجیستر allocation:** در کامپایلرها، متغیرهایی که همزمان زنده هستند نمی‌توانند در یک رجیستر باشند
4. **رنگ‌آمیزی نقشه:** کشورهای همسایه باید رنگ‌های متفاوت داشته باشند

### پیچیدگی محاسباتی

مسئله رنگ‌آمیزی گراف یک مسئله **NP-Complete** است.

## 2. مسئله مکان‌یابی تسهیلات بدون محدودیت ظرفیت (UFLP)

### تعریف مسئله

**ورودی:**
- مجموعه $F$ از تسهیلات بالقوه با هزینه باز کردن $f_i$
- مجموعه $C$ از مشتریان
- هزینه تخصیص $c_{ij}$ برای تخصیص مشتری $j$ به تسهیل $i$

**هدف:**
- انتخاب زیرمجموعه‌ای از تسهیلات برای باز کردن
- تخصیص هر مشتری به یکی از تسهیلات باز
- به گونه‌ای که مجموع هزینه‌ها حداقل شود

**فرمول‌بندی ریاضی:**

$$\text{minimize} \quad \sum_{i \in F} f_i y_i + \sum_{i \in F} \sum_{j \in C} c_{ij} x_{ij}$$

### کاربردها

1. **مکان‌یابی انبارها:** تعیین محل انبارها و تخصیص فروشگاه‌ها
2. **مکان‌یابی بیمارستان:** تعیین محل بیمارستان‌ها برای پوشش جمعیت
3. **طراحی شبکه:** مکان‌یابی سرورها و روترها
4. **زنجیره تأمین:** تعیین محل مراکز توزیع

### پیچیدگی محاسباتی

مسئله UFLP یک مسئله **NP-Hard** است.

def create_graph_instance(n_vertices, edge_probability=0.3, seed=None):
    """ایجاد یک instance تصادفی برای رنگ‌آمیزی گراف"""
    if seed:
        np.random.seed(seed)
    
    G = nx.erdos_renyi_graph(n_vertices, edge_probability, seed=seed)
    adj_matrix = nx.to_numpy_array(G).astype(int)
    
    return G, adj_matrix

def is_valid_coloring(coloring, adj_matrix):
    """بررسی معتبر بودن رنگ‌آمیزی"""
    n = len(coloring)
    for i in range(n):
        for j in range(i+1, n):
            if adj_matrix[i][j] == 1 and coloring[i] == coloring[j]:
                return False
    return True

def count_conflicts(coloring, adj_matrix):
    """شمارش تعداد تضادها در رنگ‌آمیزی"""
    conflicts = 0
    n = len(coloring)
    for i in range(n):
        for j in range(i+1, n):
            if adj_matrix[i][j] == 1 and coloring[i] == coloring[j]:
                conflicts += 1
    return conflicts

def num_colors_used(coloring):
    """تعداد رنگ‌های استفاده شده"""
    return len(set(coloring))

def greedy_coloring(adj_matrix):
    """الگوریتم حریصانه برای رنگ‌آمیزی اولیه"""
    n = len(adj_matrix)
    coloring = [-1] * n
    
    for vertex in range(n):
        # رنگ‌های استفاده شده توسط همسایه‌ها
        neighbor_colors = set()
        for neighbor in range(n):
            if adj_matrix[vertex][neighbor] == 1 and coloring[neighbor] != -1:
                neighbor_colors.add(coloring[neighbor])
        
        # کوچکترین رنگ موجود
        color = 0
        while color in neighbor_colors:
            color += 1
        coloring[vertex] = color
    
    return coloring

def generate_random_coloring(n_vertices, max_colors):
    """تولید رنگ‌آمیزی تصادفی"""
    return [random.randint(0, max_colors-1) for _ in range(n_vertices)]

def get_coloring_neighbors(coloring, adj_matrix):
    """تولید همسایگان یک رنگ‌آمیزی (تغییر رنگ یک راس)"""
    neighbors = []
    n = len(coloring)
    max_color = max(coloring)
    
    for vertex in range(n):
        for new_color in range(max_color + 2):  # شامل یک رنگ جدید
            if new_color != coloring[vertex]:
                new_coloring = coloring[:]
                new_coloring[vertex] = new_color
                neighbors.append(new_coloring)
    
    return neighbors

def local_search_graph_coloring(initial_coloring, adj_matrix, max_iterations=1000):
    """جستجوی محلی برای رنگ‌آمیزی گراف"""
    current = initial_coloring[:]
    current_colors = num_colors_used(current)
    current_conflicts = count_conflicts(current, adj_matrix)
    
    iterations = 0
    
    while iterations < max_iterations and current_conflicts > 0:
        iterations += 1
        improved = False
        
        # تلاش برای کاهش تضادها
        for vertex in range(len(current)):
            # رنگ‌های ممکن برای این راس
            neighbor_colors = set()
            for neighbor in range(len(current)):
                if adj_matrix[vertex][neighbor] == 1:
                    neighbor_colors.add(current[neighbor])
            
            # انتخاب بهترین رنگ
            best_color = current[vertex]
            best_conflicts = current_conflicts
            
            for color in range(max(current) + 1):
                if color not in neighbor_colors:
                    new_coloring = current[:]
                    new_coloring[vertex] = color
                    new_conflicts = count_conflicts(new_coloring, adj_matrix)
                    
                    if new_conflicts < best_conflicts:
                        best_color = color
                        best_conflicts = new_conflicts
                        improved = True
            
            if improved:
                current[vertex] = best_color
                current_conflicts = best_conflicts
                break
        
        if not improved:
            break
    
    # تلاش برای کاهش تعداد رنگ‌ها
    if current_conflicts == 0:
        current_colors = num_colors_used(current)
        # نرمال‌سازی رنگ‌ها
        color_map = {old: new for new, old in enumerate(sorted(set(current)))}
        current = [color_map[c] for c in current]
    
    return current, num_colors_used(current), current_conflicts, iterations

def msls_graph_coloring(adj_matrix, num_starts=10, max_iterations=1000):
    """MSLS برای رنگ‌آمیزی گراف"""
    n = len(adj_matrix)
    best_coloring = None
    best_num_colors = float('inf')
    best_conflicts = float('inf')
    
    results = []
    
    for start in range(num_starts):
        # تولید جواب اولیه
        if start == 0:
            initial = greedy_coloring(adj_matrix)
        else:
            max_colors = min(n, 10 + start)
            initial = generate_random_coloring(n, max_colors)
        
        # جستجوی محلی
        coloring, num_colors, conflicts, iters = local_search_graph_coloring(
            initial, adj_matrix, max_iterations
        )
        
        results.append({
            'start': start,
            'num_colors': num_colors,
            'conflicts': conflicts,
            'iterations': iters
        })
        
        # به‌روزرسانی بهترین جواب
        if conflicts < best_conflicts or (conflicts == best_conflicts and num_colors < best_num_colors):
            best_coloring = coloring
            best_num_colors = num_colors
            best_conflicts = conflicts
    
    return best_coloring, best_num_colors, best_conflicts, results

    - قیود:
      * Σ x_ij = 1 برای هر مشتری j (هر مشتری باید سرویس بگیرد)
      * x_ij ≤ y_i برای همه i,j (فقط از تسهیلات باز سرویس بگیرد)
    
    🎯 کاربردها:
    - مکان‌یابی انبارها
    - مکان‌یابی مراکز توزیع

    - مکان‌یابی مراکز خدماتی
    
    📊 پیچیدگی:
    - مسئله NP-Hard است
    - الگوریتم‌های تقریبی با نسبت تقریب ثابت وجود دارد
    """
    print(explanation)
    return explanation

def create_uflp_instance(n_facilities, n_customers, seed=None):
    """ایجاد instance تصادفی برای UFLP"""
    if seed:
        np.random.seed(seed)
    
    # مختصات تسهیلات و مشتریان
    facility_coords = np.random.rand(n_facilities, 2) * 100
    customer_coords = np.random.rand(n_customers, 2) * 100
    
    # هزینه باز کردن تسهیلات
    opening_costs = np.random.uniform(50, 200, n_facilities)
    
    # هزینه سرویس‌دهی (بر اساس فاصله)
    service_costs = np.zeros((n_facilities, n_customers))
    for i in range(n_facilities):
        for j in range(n_customers):
            distance = np.linalg.norm(facility_coords[i] - customer_coords[j])
            service_costs[i, j] = distance
    
    return {
        'n_facilities': n_facilities,
        'n_customers': n_customers,
        'facility_coords': facility_coords,
        'customer_coords': customer_coords,
        'opening_costs': opening_costs,
        'service_costs': service_costs
    }

def calc_uflp_cost(solution, instance):
    """محاسبه هزینه کل یک جواب UFLP"""
    open_facilities, assignments = solution
    
    # هزینه باز کردن تسهیلات
    opening_cost = sum(instance['opening_costs'][i] for i in open_facilities)
    
    # هزینه سرویس‌دهی
    service_cost = sum(
        instance['service_costs'][assignments[j], j] 
        for j in range(instance['n_customers'])
    )
    
    return opening_cost + service_cost

def is_valid_uflp_solution(solution, instance):
    """بررسی معتبر بودن جواب UFLP"""
    open_facilities, assignments = solution
    
    # همه مشتریان باید تخصیص داده شده باشند
    if len(assignments) != instance['n_customers']:
        return False
    
    # همه تخصیص‌ها باید به تسهیلات باز باشد
    for facility in assignments:
        if facility not in open_facilities:
            return False
    
    return True

def greedy_uflp(instance):
    """الگوریتم حریصانه برای UFLP"""
    n_facilities = instance['n_facilities']
    n_customers = instance['n_customers']
    
    open_facilities = set()
    assignments = [-1] * n_customers
    
    # برای هر مشتری، بهترین تسهیلات را پیدا کن
    for j in range(n_customers):
        best_cost = float('inf')
        best_facility = -1
        
        for i in range(n_facilities):
            # هزینه باز کردن (اگر باز نیست) + هزینه سرویس‌دهی
            opening_cost = 0 if i in open_facilities else instance['opening_costs'][i]
            service_cost = instance['service_costs'][i, j]
            total_cost = opening_cost + service_cost
            
            if total_cost < best_cost:
                best_cost = total_cost
                best_facility = i
        
        assignments[j] = best_facility
        open_facilities.add(best_facility)
    
    return (open_facilities, assignments)

def generate_random_uflp_solution(instance):
    """تولید جواب تصادفی برای UFLP"""
    n_facilities = instance['n_facilities']
    n_customers = instance['n_customers']
    
    # باز کردن تعدادی تسهیلات تصادفی
    num_open = random.randint(1, min(n_facilities, n_customers))
    open_facilities = set(random.sample(range(n_facilities), num_open))
    
    # تخصیص هر مشتری به نزدیک‌ترین تسهیلات باز
    assignments = []
    for j in range(n_customers):
        best_facility = min(open_facilities, 
                          key=lambda i: instance['service_costs'][i, j])
        assignments.append(best_facility)
    
    return (open_facilities, assignments)

def local_search_uflp(initial_solution, instance, max_iterations=1000):
    """جستجوی محلی برای UFLP"""
    current_solution = initial_solution
    current_cost = calc_uflp_cost(current_solution, instance)
    
    iterations = 0
    
    while iterations < max_iterations:
        iterations += 1
        improved = False
        
        open_facilities, assignments = current_solution
        
        # حرکت 1: تغییر تخصیص یک مشتری
        for j in range(instance['n_customers']):
            for new_facility in open_facilities:
                if new_facility != assignments[j]:
                    new_assignments = assignments[:]
                    new_assignments[j] = new_facility
                    new_solution = (open_facilities, new_assignments)
                    new_cost = calc_uflp_cost(new_solution, instance)
                    
                    if new_cost < current_cost:
                        current_solution = new_solution
                        current_cost = new_cost
                        improved = True
                        break
            if improved:
                break
        
        if not improved:
            # حرکت 2: باز/بسته کردن یک تسهیلات
            for i in range(instance['n_facilities']):
                if i in open_facilities:
                    # تلاش برای بستن تسهیلات i
                    if len(open_facilities) > 1:
                        new_open = open_facilities - {i}
                        # تخصیص مجدد مشتریان این تسهیلات
                        new_assignments = []
                        for j in range(instance['n_customers']):
                            if assignments[j] == i:
                                best = min(new_open, 
                                         key=lambda f: instance['service_costs'][f, j])
                                new_assignments.append(best)
                            else:
                                new_assignments.append(assignments[j])
                        
                        new_solution = (new_open, new_assignments)
                        new_cost = calc_uflp_cost(new_solution, instance)
                        
                        if new_cost < current_cost:
                            current_solution = new_solution
                            current_cost = new_cost
                            improved = True
                            break
                else:
                    # تلاش برای باز کردن تسهیلات i
                    new_open = open_facilities | {i}
                    # تخصیص مجدد مشتریان به تسهیلات جدید اگر بهتر است
                    new_assignments = []
                    for j in range(instance['n_customers']):
                        if instance['service_costs'][i, j] < instance['service_costs'][assignments[j], j]:
                            new_assignments.append(i)
                        else:
                            new_assignments.append(assignments[j])
                    
                    new_solution = (new_open, new_assignments)
                    new_cost = calc_uflp_cost(new_solution, instance)
                    
                    if new_cost < current_cost:
                        current_solution = new_solution
                        current_cost = new_cost
                        improved = True
                        break
        
        if not improved:
            break
    
    return current_solution, current_cost, iterations

def msls_uflp(instance, num_starts=10, max_iterations=1000):
    """MSLS برای UFLP"""
    best_solution = None
    best_cost = float('inf')
    
    results = []
    
    for start in range(num_starts):
        # تولید جواب اولیه
        if start == 0:
            initial = greedy_uflp(instance)
        else:
            initial = generate_random_uflp_solution(instance)
        
        initial_cost = calc_uflp_cost(initial, instance)
        
        # جستجوی محلی
        solution, cost, iters = local_search_uflp(initial, instance, max_iterations)
        
        results.append({
            'start': start,
            'initial_cost': initial_cost,
            'final_cost': cost,
            'improvement': initial_cost - cost,
            'iterations': iters
        })
        
        # به‌روزرسانی بهترین جواب
        if cost < best_cost:
            best_solution = solution
            best_cost = cost
    
    return best_solution, best_cost, results

def create_graph_instance(n_vertices, edge_probability=0.3, seed=None):
    """ایجاد یک instance تصادفی برای رنگ‌آمیزی گراف"""
    if seed:
        np.random.seed(seed)
    
    G = nx.erdos_renyi_graph(n_vertices, edge_probability, seed=seed)
    adj_matrix = nx.to_numpy_array(G).astype(int)
    
    return G, adj_matrix

def is_valid_coloring(coloring, adj_matrix):
    """بررسی معتبر بودن رنگ‌آمیزی"""
    n = len(coloring)
    for i in range(n):
        for j in range(i+1, n):
            if adj_matrix[i][j] == 1 and coloring[i] == coloring[j]:
                return False
    return True

def count_conflicts(coloring, adj_matrix):
    """شمارش تعداد تضادها در رنگ‌آمیزی"""
    conflicts = 0
    n = len(coloring)
    for i in range(n):
        for j in range(i+1, n):
            if adj_matrix[i][j] == 1 and coloring[i] == coloring[j]:
                conflicts += 1
    return conflicts

def num_colors_used(coloring):
    """تعداد رنگ‌های استفاده شده"""
    return len(set(coloring))

def greedy_coloring(adj_matrix):
    """الگوریتم حریصانه برای رنگ‌آمیزی اولیه"""
    n = len(adj_matrix)
    coloring = [-1] * n
    
    for vertex in range(n):
        # رنگ‌های استفاده شده توسط همسایه‌ها
        neighbor_colors = set()
        for neighbor in range(n):
            if adj_matrix[vertex][neighbor] == 1 and coloring[neighbor] != -1:
                neighbor_colors.add(coloring[neighbor])
        
        # کوچکترین رنگ موجود
        color = 0
        while color in neighbor_colors:
            color += 1
        coloring[vertex] = color
    
    return coloring

def generate_random_coloring(n_vertices, max_colors):
    """تولید رنگ‌آمیزی تصادفی"""
    return [random.randint(0, max_colors-1) for _ in range(n_vertices)]

def get_coloring_neighbors(coloring, adj_matrix):
    """تولید همسایگان یک رنگ‌آمیزی (تغییر رنگ یک راس)"""
    neighbors = []
    n = len(coloring)
    max_color = max(coloring)
    
    for vertex in range(n):
        for new_color in range(max_color + 2):  # شامل یک رنگ جدید
            if new_color != coloring[vertex]:
                new_coloring = coloring[:]
                new_coloring[vertex] = new_color
                neighbors.append(new_coloring)
    
    return neighbors

def local_search_graph_coloring(initial_coloring, adj_matrix, max_iterations=1000):
    """جستجوی محلی برای رنگ‌آمیزی گراف"""
    current = initial_coloring[:]
    current_colors = num_colors_used(current)
    current_conflicts = count_conflicts(current, adj_matrix)
    
    iterations = 0
    
    while iterations < max_iterations and current_conflicts > 0:
        iterations += 1
        improved = False
        
        # تلاش برای کاهش تضادها
        for vertex in range(len(current)):
            # رنگ‌های ممکن برای این راس
            neighbor_colors = set()
            for neighbor in range(len(current)):
                if adj_matrix[vertex][neighbor] == 1:
                    neighbor_colors.add(current[neighbor])
            
            # انتخاب بهترین رنگ
            best_color = current[vertex]
            best_conflicts = current_conflicts
            
            for color in range(max(current) + 1):
                if color not in neighbor_colors:
                    new_coloring = current[:]
                    new_coloring[vertex] = color
                    new_conflicts = count_conflicts(new_coloring, adj_matrix)
                    
                    if new_conflicts < best_conflicts:
                        best_color = color
                        best_conflicts = new_conflicts
                        improved = True
            
            if improved:
                current[vertex] = best_color
                current_conflicts = best_conflicts
                break
        
        if not improved:
            break
    
    # تلاش برای کاهش تعداد رنگ‌ها
    if current_conflicts == 0:
        current_colors = num_colors_used(current)
        # نرمال‌سازی رنگ‌ها
        color_map = {old: new for new, old in enumerate(sorted(set(current)))}
        current = [color_map[c] for c in current]
    
    return current, num_colors_used(current), current_conflicts, iterations

def msls_graph_coloring(adj_matrix, num_starts=10, max_iterations=1000):
    """MSLS برای رنگ‌آمیزی گراف"""
    n = len(adj_matrix)
    best_coloring = None
    best_num_colors = float('inf')
    best_conflicts = float('inf')
    
    results = []
    
    for start in range(num_starts):
        # تولید جواب اولیه
        if start == 0:
            initial = greedy_coloring(adj_matrix)
        else:
            max_colors = min(n, 10 + start)
            initial = generate_random_coloring(n, max_colors)
        
        # جستجوی محلی
        coloring, num_colors, conflicts, iters = local_search_graph_coloring(
            initial, adj_matrix, max_iterations
        )
        
        results.append({
            'start': start,
            'num_colors': num_colors,
            'conflicts': conflicts,
            'iterations': iters
        })
        
        # به‌روزرسانی بهترین جواب
        if conflicts < best_conflicts or (conflicts == best_conflicts and num_colors < best_num_colors):
            best_coloring = coloring
            best_num_colors = num_colors
            best_conflicts = conflicts
    
    return best_coloring, best_num_colors, best_conflicts, results

def explain_uflp():
    """توضیح مسئله UFLP"""
    explanation = """
    🏭 مسئله مکان‌یابی تسهیلات بدون محدودیت ظرفیت (UFLP):
    
    📋 تعریف مسئله:
    - مجموعه‌ای از مکان‌های بالقوه برای تسهیلات: F
    - مجموعه‌ای از مشتریان: C
    - هزینه باز کردن تسهیلات: f_i
    - هزینه سرویس‌دهی مشتری j از تسهیلات i: c_ij
    
    🎯 هدف:
    - انتخاب زیرمجموعه‌ای از تسهیلات برای باز کردن
    - تخصیص هر مشتری به یک تسهیلات باز
    - حداقل‌سازی هزینه کل (هزینه باز کردن + هزینه سرویس‌دهی)
    
    🔢 فرمول‌بندی ریاضی:
    - متغیرها:
      * y_i ∈ {0,1}: تسهیلات i باز است یا خیر
      * x_ij ∈ {0,1}: مشتری j از تسهیلات i سرویس می‌گیرد
    
    - تابع هدف:
      minimize Σ f_i * y_i + Σ Σ c_ij * x_ij
    
    - قیود:
      * Σ x_ij = 1 برای هر مشتری j (هر مشتری باید سرویس بگیرد)
      * x_ij ≤ y_i برای همه i,j (فقط از تسهیلات باز سرویس بگیرد)
    
    🎯 کاربردها:
    - مکان‌یابی انبارها
    - مکان‌یابی مراکز توزیع
    - طراحی شبکه‌های ارتباطی
    - مکان‌یابی مراکز خدماتی
    
    📊 پیچیدگی:
    - مسئله NP-Hard است
    - الگوریتم‌های تقریبی با نسبت تقریب ثابت وجود دارد
    """
    print(explanation)
    return explanation

def create_uflp_instance(n_facilities, n_customers, seed=None):
    """ایجاد instance تصادفی برای UFLP"""
    if seed:
        np.random.seed(seed)
    
    # مختصات تسهیلات و مشتریان
    facility_coords = np.random.rand(n_facilities, 2) * 100
    customer_coords = np.random.rand(n_customers, 2) * 100
    
    # هزینه باز کردن تسهیلات
    opening_costs = np.random.uniform(50, 200, n_facilities)
    
    # هزینه سرویس‌دهی (بر اساس فاصله)
    service_costs = np.zeros((n_facilities, n_customers))
    for i in range(n_facilities):
        for j in range(n_customers):
            distance = np.linalg.norm(facility_coords[i] - customer_coords[j])
            service_costs[i, j] = distance
    
    return {
        'n_facilities': n_facilities,
        'n_customers': n_customers,
        'facility_coords': facility_coords,
        'customer_coords': customer_coords,
        'opening_costs': opening_costs,
        'service_costs': service_costs
    }

def calc_uflp_cost(solution, instance):
    """محاسبه هزینه کل یک جواب UFLP"""
    open_facilities, assignments = solution
    
    # هزینه باز کردن تسهیلات
    opening_cost = sum(instance['opening_costs'][i] for i in open_facilities)
    
    # هزینه سرویس‌دهی
    service_cost = sum(
        instance['service_costs'][assignments[j], j] 
        for j in range(instance['n_customers'])
    )
    
    return opening_cost + service_cost

def is_valid_uflp_solution(solution, instance):
    """بررسی معتبر بودن جواب UFLP"""
    open_facilities, assignments = solution
    
    # همه مشتریان باید تخصیص داده شده باشند
    if len(assignments) != instance['n_customers']:
        return False
    
    # همه تخصیص‌ها باید به تسهیلات باز باشد
    for facility in assignments:
        if facility not in open_facilities:
            return False
    
    return True

def greedy_uflp(instance):
    """الگوریتم حریصانه برای UFLP"""
    n_facilities = instance['n_facilities']
    n_customers = instance['n_customers']
    
    open_facilities = set()
    assignments = [-1] * n_customers
    
    # برای هر مشتری، بهترین تسهیلات را پیدا کن
    for j in range(n_customers):
        best_cost = float('inf')
        best_facility = -1
        
        for i in range(n_facilities):
            # هزینه باز کردن (اگر باز نیست) + هزینه سرویس‌دهی
            opening_cost = 0 if i in open_facilities else instance['opening_costs'][i]
            service_cost = instance['service_costs'][i, j]
            total_cost = opening_cost + service_cost
            
            if total_cost < best_cost:
                best_cost = total_cost
                best_facility = i
        
        assignments[j] = best_facility
        open_facilities.add(best_facility)
    
    return (open_facilities, assignments)

def generate_random_uflp_solution(instance):
    """تولید جواب تصادفی برای UFLP"""
    n_facilities = instance['n_facilities']
    n_customers = instance['n_customers']
    
    # باز کردن تعدادی تسهیلات تصادفی
    num_open = random.randint(1, min(n_facilities, n_customers))
    open_facilities = set(random.sample(range(n_facilities), num_open))
    
    # تخصیص هر مشتری به نزدیک‌ترین تسهیلات باز
    assignments = []
    for j in range(n_customers):
        best_facility = min(open_facilities, 
                          key=lambda i: instance['service_costs'][i, j])
        assignments.append(best_facility)
    
    return (open_facilities, assignments)

def local_search_uflp(initial_solution, instance, max_iterations=1000):
    """جستجوی محلی برای UFLP"""
    current_solution = initial_solution
    current_cost = calc_uflp_cost(current_solution, instance)
    
    iterations = 0
    
    while iterations < max_iterations:
        iterations += 1
        improved = False
        
        open_facilities, assignments = current_solution
        
        # حرکت 1: تغییر تخصیص یک مشتری
        for j in range(instance['n_customers']):
            for new_facility in open_facilities:
                if new_facility != assignments[j]:
                    new_assignments = assignments[:]
                    new_assignments[j] = new_facility
                    new_solution = (open_facilities, new_assignments)
                    new_cost = calc_uflp_cost(new_solution, instance)
                    
                    if new_cost < current_cost:
                        current_solution = new_solution
                        current_cost = new_cost
                        improved = True
                        break
            if improved:
                break
        
        if not improved:
            # حرکت 2: باز/بسته کردن یک تسهیلات
            for i in range(instance['n_facilities']):
                if i in open_facilities:
                    # تلاش برای بستن تسهیلات i
                    if len(open_facilities) > 1:
                        new_open = open_facilities - {i}
                        # تخصیص مجدد مشتریان این تسهیلات
                        new_assignments = []
                        for j in range(instance['n_customers']):
                            if assignments[j] == i:
                                best = min(new_open, 
                                         key=lambda f: instance['service_costs'][f, j])
                                new_assignments.append(best)
                            else:
                                new_assignments.append(assignments[j])
                        
                        new_solution = (new_open, new_assignments)
                        new_cost = calc_uflp_cost(new_solution, instance)
                        
                        if new_cost < current_cost:
                            current_solution = new_solution
                            current_cost = new_cost
                            improved = True
                            break
                else:
                    # تلاش برای باز کردن تسهیلات i
                    new_open = open_facilities | {i}
                    # تخصیص مجدد مشتریان به تسهیلات جدید اگر بهتر است
                    new_assignments = []
                    for j in range(instance['n_customers']):
                        if instance['service_costs'][i, j] < instance['service_costs'][assignments[j], j]:
                            new_assignments.append(i)
                        else:
                            new_assignments.append(assignments[j])
                    
                    new_solution = (new_open, new_assignments)
                    new_cost = calc_uflp_cost(new_solution, instance)
                    
                    if new_cost < current_cost:
                        current_solution = new_solution
                        current_cost = new_cost
                        improved = True
                        break
        
        if not improved:
            break
    
    return current_solution, current_cost, iterations

def msls_uflp(instance, num_starts=10, max_iterations=1000):
    """MSLS برای UFLP"""
    best_solution = None
    best_cost = float('inf')
    
    results = []
    
    for start in range(num_starts):
        # تولید جواب اولیه
        if start == 0:
            initial = greedy_uflp(instance)
        else:
            initial = generate_random_uflp_solution(instance)
        
        initial_cost = calc_uflp_cost(initial, instance)
        
        # جستجوی محلی
        solution, cost, iters = local_search_uflp(initial, instance, max_iterations)
        
        results.append({
            'start': start,
            'initial_cost': initial_cost,
            'final_cost': cost,
            'improvement': initial_cost - cost,
            'iterations': iters
        })
        
        # به‌روزرسانی بهترین جواب
        if cost < best_cost:
            best_solution = solution
            best_cost = cost
    
    return best_solution, best_cost, results

class GraphColoringProblem:
    """
    مسئله رنگ‌آمیزی گراف:
    هدف: تخصیص رنگ به راس‌های گراف به گونه‌ای که دو راس مجاور رنگ یکسان نداشته باشند
    و تعداد رنگ‌های استفاده شده حداقل باشد.
    """
    
    def __init__(self, n_vertices: int, edge_probability: float = 0.3):
        self.n = n_vertices
        self.adj_matrix = self._generate_random_graph(edge_probability)
        
    def _generate_random_graph(self, p: float) -> np.ndarray:
        """تولید گراف تصادفی"""
        adj = np.random.choice([0, 1], size=(self.n, self.n), p=[1-p, p])
        adj = np.tril(adj, -1) + np.tril(adj, -1).T
        np.fill_diagonal(adj, 0)
        return adj.astype(int)
    
    def calculate_conflicts(self, coloring: List[int]) -> int:
        """محاسبه تعداد تضادها (یال‌هایی که دو سر آن هم‌رنگ هستند)"""
        conflicts = 0
        for i in range(self.n):
            for j in range(i+1, self.n):
                if self.adj_matrix[i][j] == 1 and coloring[i] == coloring[j]:
                    conflicts += 1
        return conflicts
    
    def num_colors_used(self, coloring: List[int]) -> int:
        """تعداد رنگ‌های استفاده شده"""
        return len(set(coloring))
    
    def is_valid_coloring(self, coloring: List[int]) -> bool:
        """بررسی معتبر بودن رنگ‌آمیزی"""
        return self.calculate_conflicts(coloring) == 0


class GraphColoringLS:
    """الگوریتم Local Search برای Graph Coloring"""
    
    def __init__(self, problem: GraphColoringProblem):
        self.problem = problem
        
    def generate_initial_solution(self, max_colors: int = None) -> List[int]:
        """تولید جواب اولیه تصادفی"""
        if max_colors is None:
            max_colors = self.problem.n
        return [random.randint(0, max_colors-1) for _ in range(self.problem.n)]
    
    def get_neighbors(self, coloring: List[int]) -> List[List[int]]:
        """تولید همسایگان با تغییر رنگ یک راس"""
        neighbors = []
        max_color = max(coloring)
        
        for vertex in range(self.problem.n):
            for new_color in range(max_color + 2):  # شامل یک رنگ جدید
                if new_color != coloring[vertex]:
                    neighbor = coloring.copy()
                    neighbor[vertex] = new_color
                    neighbors.append(neighbor)
        
        return neighbors
    
    def local_search(self, max_iterations: int = 1000, mode: str = "best") -> Tuple[List[int], int, int]:
        """
        الگوریتم Local Search
        mode: "best" یا "first"
        """
        current = self.generate_initial_solution()
        current_conflicts = self.problem.calculate_conflicts(current)
        current_colors = self.problem.num_colors_used(current)
        
        iterations = 0
        start_time = time.time()
        
        while iterations < max_iterations and time.time() - start_time < 60:
            iterations += 1
            
            neighbors = self.get_neighbors(current)
            best_neighbor = None
            best_conflicts = current_conflicts
            best_colors = current_colors
            improved = False
            
            for neighbor in neighbors:
                n_conflicts = self.problem.calculate_conflicts(neighbor)
                n_colors = self.problem.num_colors_used(neighbor)
                
                # اولویت: کاهش تضاد، سپس کاهش تعداد رنگ
                if n_conflicts < best_conflicts or \
                   (n_conflicts == best_conflicts and n_colors < best_colors):
                    best_neighbor = neighbor
                    best_conflicts = n_conflicts
                    best_colors = n_colors
                    improved = True
                    
                    if mode == "first":
                        break
            
            if improved:
                current = best_neighbor
                current_conflicts = best_conflicts
                current_colors = best_colors
            else:
                break
        
        return current, current_colors, iterations


class GraphColoringMSLS:
    """Multi-Start Local Search برای Graph Coloring"""
    
    def __init__(self, problem: GraphColoringProblem):
        self.problem = problem
        self.ls = GraphColoringLS(problem)
    
    def multi_start_search(self, num_starts: int = 10, max_iterations: int = 1000) -> Tuple[List[int], int, float]:
        """اجرای MSLS با چندین نقطه شروع"""

class UFLPProblem:
    """
    مسئله مکان‌یابی تسهیلات بدون محدودیت ظرفیت:
    هدف: انتخاب زیرمجموعه‌ای از تسهیلات برای باز کردن و تخصیص مشتریان به آنها
    به گونه‌ای که مجموع هزینه‌های باز کردن و تخصیص حداقل شود.
    """
    
    def __init__(self, n_facilities: int, n_customers: int):
        self.n_facilities = n_facilities
        self.n_customers = n_customers
        
        # هزینه باز کردن تسهیلات
        self.opening_costs = np.random.randint(100, 500, n_facilities)
        
        # هزینه تخصیص (فاصله بین مشتری و تسهیل)
        self.assignment_costs = np.random.randint(10, 100, (n_customers, n_facilities))
    
    def calculate_cost(self, open_facilities: List[int], assignments: List[int]) -> float:
        """محاسبه هزینه کل"""
        # هزینه باز کردن تسهیلات
        opening_cost = sum(self.opening_costs[f] for f in open_facilities)
        
        # هزینه تخصیص مشتریان
        assignment_cost = sum(self.assignment_costs[c][assignments[c]] 
                            for c in range(self.n_customers))
        
        return opening_cost + assignment_cost
    
    def is_valid_solution(self, open_facilities: List[int], assignments: List[int]) -> bool:
        """بررسی معتبر بودن جواب"""
        # همه مشتریان باید به تسهیلات باز تخصیص یابند
        return all(assignments[c] in open_facilities for c in range(self.n_customers))


class UFLPLS:
    """الگوریتم Local Search برای UFLP"""
    
    def __init__(self, problem: UFLPProblem):
        self.problem = problem
    
    def generate_initial_solution(self) -> Tuple[List[int], List[int]]:
        """تولید جواب اولیه: همه تسهیلات باز، هر مشتری به نزدیک‌ترین تخصیص"""
        open_facilities = list(range(self.problem.n_facilities))
        
        # تخصیص هر مشتری به ارزان‌ترین تسهیل
        assignments = []
        for c in range(self.problem.n_customers):
            best_facility = min(range(self.problem.n_facilities),
                              key=lambda f: self.problem.assignment_costs[c][f])
            assignments.append(best_facility)
        
        return open_facilities, assignments
    
    def optimize_assignments(self, open_facilities: List[int]) -> List[int]:
        """بهینه‌سازی تخصیص مشتریان به تسهیلات باز"""
        assignments = []
        for c in range(self.problem.n_customers):
            best_facility = min(open_facilities,
                              key=lambda f: self.problem.assignment_costs[c][f])
            assignments.append(best_facility)
        return assignments
    
    def local_search(self, max_iterations: int = 1000, mode: str = "best") -> Tuple[List[int], List[int], float, int]:
        """الگوریتم Local Search"""
        open_facilities, assignments = self.generate_initial_solution()
        current_cost = self.problem.calculate_cost(open_facilities, assignments)
        
        iterations = 0
        start_time = time.time()
        
        while iterations < max_iterations and time.time() - start_time < 60:
            iterations += 1
            improved = False
            best_cost = current_cost
            best_open = open_facilities
            best_assign = assignments
            
            # حرکت 1: بستن یک تسهیل
            for f in open_facilities:
                if len(open_facilities) > 1:  # حداقل یک تسهیل باید باز باشد
                    new_open = [x for x in open_facilities if x != f]
                    new_assign = self.optimize_assignments(new_open)
                    new_cost = self.problem.calculate_cost(new_open, new_assign)
                    
                    if new_cost < best_cost:
                        best_cost = new_cost
                        best_open = new_open
                        best_assign = new_assign
                        improved = True
                        
                        if mode == "first":
                            break
            
            # حرکت 2: باز کردن یک تسهیل بسته
            if not improved or mode == "best":
                closed_facilities = [f for f in range(self.problem.n_facilities) 
                                   if f not in open_facilities]
                
                for f in closed_facilities:
                    new_open = open_facilities + [f]
                    new_assign = self.optimize_assignments(new_open)
                    new_cost = self.problem.calculate_cost(new_open, new_assign)
                    
                    if new_cost < best_cost:
                        best_cost = new_cost
                        best_open = new_open
                        best_assign = new_assign
                        improved = True
                        
                        if mode == "first":
                            break
            
            if improved:
                open_facilities = best_open
                assignments = best_assign
                current_cost = best_cost
            else:
                break
        
        elapsed = time.time() - start_time
        return open_facilities, assignments, current_cost, iterations


class UFLPMSLS:
    """Multi-Start Local Search برای UFLP"""
    
    def __init__(self, problem: UFLPProblem):

        self.ls = UFLPLS(problem)

        # تخصیص بهینه مشتریان
        assignments = self.ls.optimize_assignments(open_facilities)
        
        return open_facilities, assignments
    
    def multi_start_search(self, num_starts: int = 10, max_iterations: int = 1000) -> Tuple[List[int], List[int], float, float]:
        """اجرای MSLS"""
        best_open = None
        best_assign = None
        best_cost = float('inf')
        
        start_time = time.time()
        
        for i in range(num_starts):
            # شروع از یک نقطه تصادفی
            init_open, init_assign = self.generate_random_start()
            
            # اجرای Local Search
            open_fac, assign, cost, iters = self.ls.local_search(max_iterations)
            
            if cost < best_cost:

class GraphColoringProblem:
    """مسئله رنگ‌آمیزی گراف"""
    
    def __init__(self, n_vertices: int, edge_probability: float = 0.3):
        self.n = n_vertices
        self.adj_matrix = self._generate_random_graph(edge_probability)
        
    def _generate_random_graph(self, p: float) -> np.ndarray:
        adj = np.random.choice([0, 1], size=(self.n, self.n), p=[1-p, p])
        adj = np.tril(adj, -1) + np.tril(adj, -1).T
        np.fill_diagonal(adj, 0)
        return adj.astype(int)
    
    def calculate_conflicts(self, coloring: List[int]) -> int:
        conflicts = 0
        for i in range(self.n):
            for j in range(i+1, self.n):
                if self.adj_matrix[i][j] == 1 and coloring[i] == coloring[j]:
                    conflicts += 1
        return conflicts
    
    def num_colors_used(self, coloring: List[int]) -> int:
        return len(set(coloring))


class UFLPProblem:
    """مسئله مکان‌یابی تسهیلات"""
    
    def __init__(self, n_facilities: int, n_customers: int):
        self.n_facilities = n_facilities
        self.n_customers = n_customers
        self.opening_costs = np.random.randint(100, 500, n_facilities)
        self.assignment_costs = np.random.randint(10, 100, (n_customers, n_facilities))
    
    def calculate_cost(self, open_facilities: List[int], assignments: List[int]) -> float:
        opening_cost = sum(self.opening_costs[f] for f in open_facilities)
        assignment_cost = sum(self.assignment_costs[c][assignments[c]] 
                            for c in range(self.n_customers))
        return opening_cost + assignment_cost

def solve_graph_coloring_cplex(problem: GraphColoringProblem, max_colors: int = None, time_limit: int = 60):
    """حل مسئله Graph Coloring با CPLEX"""
    
    if not CPLEX_AVAILABLE:
        return None
    
    try:
        n = problem.n
        if max_colors is None:
            max_colors = n
        
        model = Model(name='GraphColoring')
        model.set_time_limit(time_limit)
        
        # متغیرها
        x = {}
        for i in range(n):
            for c in range(max_colors):
                x[i, c] = model.binary_var(name=f'x_{i}_{c}')
        
        y = {}
        for c in range(max_colors):
            y[c] = model.binary_var(name=f'y_{c}')
        
        # محدودیت‌ها
        for i in range(n):
            model.add_constraint(model.sum(x[i, c] for c in range(max_colors)) == 1)
        
        for i in range(n):
            for j in range(i+1, n):
                if problem.adj_matrix[i][j] == 1:
                    for c in range(max_colors):
                        model.add_constraint(x[i, c] + x[j, c] <= 1)
        
        for i in range(n):
            for c in range(max_colors):
                model.add_constraint(x[i, c] <= y[c])
        
        # تابع هدف
        model.minimize(model.sum(y[c] for c in range(max_colors)))
        
        # حل
        start_time = time.time()
        solution = model.solve(log_output=False)
        elapsed = time.time() - start_time
        
        if solution:
            coloring = []
            for i in range(n):
                for c in range(max_colors):
                    if x[i, c].solution_value > 0.5:
                        coloring.append(c)
                        break
            
            num_colors = int(solution.objective_value)
            
            return {
                'coloring': coloring,
                'num_colors': num_colors,
                'conflicts': problem.calculate_conflicts(coloring),
                'time': elapsed,
                'status': 'optimal'
            }
        else:
            return None
            
    except Exception as e:
        print(f"  ⚠️  خطا در CPLEX: {str(e)[:100]}")
        return None

def solve_uflp_cplex(problem: UFLPProblem, time_limit: int = 60):
    """حل مسئله UFLP با CPLEX"""
    
    if not CPLEX_AVAILABLE:
        return None
    
    try:
        n_fac = problem.n_facilities
        n_cust = problem.n_customers
        
        model = Model(name='UFLP')
        model.set_time_limit(time_limit)
        
        # متغیرها
        y = {}
        for i in range(n_fac):
            y[i] = model.binary_var(name=f'y_{i}')
        
        x = {}
        for i in range(n_fac):
            for j in range(n_cust):
                x[i, j] = model.binary_var(name=f'x_{i}_{j}')
        
        # محدودیت‌ها
        for j in range(n_cust):
            model.add_constraint(model.sum(x[i, j] for i in range(n_fac)) == 1)
        
        for i in range(n_fac):
            for j in range(n_cust):
                model.add_constraint(x[i, j] <= y[i])
        
        # تابع هدف
        opening_cost = model.sum(problem.opening_costs[i] * y[i] for i in range(n_fac))
        assignment_cost = model.sum(problem.assignment_costs[j][i] * x[i, j] 
                                    for i in range(n_fac) for j in range(n_cust))

        # حل

        elapsed = time.time() - start_time

class GraphColoringLS:
    """الگوریتم Local Search ساده برای Graph Coloring"""
    
    def __init__(self, problem: GraphColoringProblem):
        self.problem = problem
    
    def solve(self, max_iterations: int = 1000):
        n = self.problem.n
        current = [random.randint(0, n-1) for _ in range(n)]
        
        start_time = time.time()
        
        for _ in range(max_iterations):
            improved = False
            best_coloring = current
            best_colors = self.problem.num_colors_used(current)
            
            for v in range(n):
                for c in range(max(current) + 2):
                    if c != current[v]:
                        neighbor = current.copy()
                        neighbor[v] = c
                        
                        if self.problem.calculate_conflicts(neighbor) == 0:
                            n_colors = self.problem.num_colors_used(neighbor)
                            if n_colors < best_colors:
                                best_coloring = neighbor
                                best_colors = n_colors
                                improved = True
            
            if improved:
                current = best_coloring
            else:
                break
        
        elapsed = time.time() - start_time
        
        return {
            'coloring': current,
            'num_colors': self.problem.num_colors_used(current),
            'conflicts': self.problem.calculate_conflicts(current),
            'time': elapsed
        }


class UFLPLS:
    """الگوریتم Local Search ساده برای UFLP"""
    
    def __init__(self, problem: UFLPProblem):
        self.problem = problem
    
    def solve(self, max_iterations: int = 1000):
        n_fac = self.problem.n_facilities
        n_cust = self.problem.n_customers
        
        open_facilities = list(range(n_fac))
        assignments = [min(range(n_fac), 
                          key=lambda f: self.problem.assignment_costs[c][f])
                      for c in range(n_cust)]
        
        current_cost = self.problem.calculate_cost(open_facilities, assignments)
        
        start_time = time.time()
        
        for _ in range(max_iterations):
            improved = False
            
            for f in open_facilities:
                if len(open_facilities) > 1:
                    new_open = [x for x in open_facilities if x != f]
                    new_assign = [min(new_open, 
                                     key=lambda i: self.problem.assignment_costs[c][i])
                                 for c in range(n_cust)]
                    new_cost = self.problem.calculate_cost(new_open, new_assign)
                    
                    if new_cost < current_cost:
                        open_facilities = new_open
                        assignments = new_assign
                        current_cost = new_cost
                        improved = True
                        break
            
            if not improved:
                break
        
        elapsed = time.time() - start_time
        
        return {
            'open_facilities': open_facilities,
            'assignments': assignments,
            'cost': current_cost,
            'time': elapsed
        }

\section{Introduction}

In this assignment, we study two classic combinatorial optimization problems:
\begin{enumerate}
    \item \textbf{Graph Coloring Problem}
    \item \textbf{Uncapacitated Facility Location Problem (UFLP)}
\end{enumerate}

For each problem, Local Search (LS) and Multi-Start Local Search (MSLS) algorithms have been designed and implemented. The results are also compared with CPLEX solver.

\section{Graph Coloring Problem}

\subsection{Problem Definition}

The Graph Coloring Problem is one of the classic NP-Complete problems. The goal is to assign colors to vertices of a graph such that:
\begin{itemize}
    \item No two adjacent vertices have the same color
    \item The number of colors used is minimized
\end{itemize}

\subsection{Mathematical Formulation}

\textbf{Variables:}
\begin{itemize}
    \item $x_{ij} \in \{0,1\}$: vertex $i$ has color $j$
    \item $y_j \in \{0,1\}$: color $j$ is used
\end{itemize}

\textbf{Objective Function:}
\begin{equation}
\min \sum_{j=1}^{n} y_j
\end{equation}

\textbf{Constraints:}
\begin{align}
\sum_{j=1}^{n} x_{ij} &= 1 \quad \forall i \in V \\
x_{ij} + x_{kj} &\leq y_j \quad \forall (i,k) \in E, \forall j \\
x_{ij}, y_j &\in \{0,1\}
\end{align}

\subsection{Local Search Algorithm}

\subsubsection{Solution Structure}

A solution is represented as an array of colors:
\[
\text{solution} = [c_1, c_2, \ldots, c_n]
\]
where $c_i$ is the color of vertex $i$.

\subsubsection{Neighborhood}

Two types of moves are used to generate neighbors:

\textbf{1. Recolor:}
\begin{itemize}
    \item Select a random vertex
    \item Change its color to another color
    \item Accept if the number of colors decreases
\end{itemize}

\textbf{2. Merge Colors:}
\begin{itemize}
    \item Select two colors
    \item Change all vertices with the second color to the first color
    \item Accept if the solution is valid
\end{itemize}

\subsubsection{Algorithm Pseudocode}

\begin{algorithm}
\caption{Local Search for Graph Coloring}
\begin{algorithmic}[1]
\State $s \gets$ GenerateInitialSolution()
\State $best \gets s$
\Repeat
    \State $improved \gets False$
    \For{each neighbor $s'$ of $s$}
        \If{$f(s') < f(best)$}
            \State $best \gets s'$
            \State $improved \gets True$
        \EndIf
    \EndFor
    \State $s \gets best$
\Until{not $improved$}
\State \Return $best$
\end{algorithmic}
\end{algorithm}

\subsection{Multi-Start Local Search Algorithm}

MSLS runs the LS algorithm multiple times with different starting points and returns the best solution.

\begin{algorithm}
\caption{Multi-Start Local Search}
\begin{algorithmic}[1]
\State $best \gets \infty$
\For{$i = 1$ to $num\_starts$}
    \State $s \gets$ LocalSearch()
    \If{$f(s) < f(best)$}
        \State $best \gets s$
    \EndIf
\EndFor
\State \Return $best$
\end{algorithmic}
\end{algorithm}

\section{Uncapacitated Facility Location Problem}

\subsection{Problem Definition}

In the UFLP, the goal is to select facilities to open and assign customers to them such that the total cost is minimized:
\begin{itemize}
    \item Cost of opening facilities
    \item Cost of assigning customers to facilities
\end{itemize}

\subsection{Mathematical Formulation}

\textbf{Variables:}
\begin{itemize}
    \item $y_j \in \{0,1\}$: facility $j$ is open
    \item $x_{ij} \in \{0,1\}$: customer $i$ is assigned to facility $j$
\end{itemize}

\textbf{Objective Function:}
\begin{equation}
\min \sum_{j=1}^{m} f_j y_j + \sum_{i=1}^{n} \sum_{j=1}^{m} c_{ij} x_{ij}
\end{equation}

\textbf{Constraints:}
\begin{align}
\sum_{j=1}^{m} x_{ij} &= 1 \quad \forall i \\
x_{ij} &\leq y_j \quad \forall i,j \\
x_{ij}, y_j &\in \{0,1\}
\end{align}

\subsection{Local Search Algorithm}

\subsubsection{Solution Structure}

A solution consists of:
\begin{itemize}
    \item Set of open facilities: $F_{open}$
    \item Customer assignments: $assignment[i] = j$
\end{itemize}

\subsubsection{Neighborhood}

Three types of moves:

\textbf{1. Open/Close Facility:}
\begin{itemize}
    \item Open a closed facility
    \item Close an open facility (if it has no customers)
\end{itemize}

\textbf{2. Reassign Customer:}
\begin{itemize}
    \item Move a customer to a different facility
\end{itemize}

\textbf{3. Swap Facility:}
\begin{itemize}
    \item Close an open facility and open a closed one
\end{itemize}

\section{Conclusions and Recommendations}

\subsection{Key Findings}

\begin{enumerate}
    \item \textbf{MSLS is an effective method} for improving Local Search solution quality
    \item \textbf{Trade-off between quality and speed} should be chosen based on problem requirements
    \item \textbf{Graph Coloring} benefits more from MSLS than UFLP
    \item \textbf{CPLEX} is suitable for small and medium problems
    \item \textbf{LS/MSLS} are suitable for large problems and real-time applications
\end{enumerate}

\subsection{Practical Recommendations}

\subsubsection{For Graph Coloring}

\begin{itemize}
    \item \textbf{Small problems (< 15 vertices):} Use CPLEX for optimal solution
    \item \textbf{Medium problems (15-30 vertices):} MSLS with 10-20 starts
    \item \textbf{Large problems (> 30 vertices):} MSLS with 20-30 starts or metaheuristics
    \item \textbf{Real-time applications:} LS due to very high speed
\end{itemize}

\subsubsection{For UFLP}

\begin{itemize}
    \item \textbf{Small problems (< 10 facilities):} CPLEX for optimal solution
    \item \textbf{Medium problems:} LS or MSLS (quality gap is small)
    \item \textbf{Large problems:} MSLS or combination with other algorithms
    \item \textbf{Real problems:} Depending on time constraints, LS or CPLEX
\end{itemize}

\subsection{Improvement Suggestions}

\begin{enumerate}
    \item \textbf{Advanced neighborhoods:} Use more complex and intelligent moves
    \item \textbf{Combine with Tabu Search:} To avoid returning to previous solutions
    \item \textbf{Simulated Annealing:} To accept worse solutions with controlled probability
    \item \textbf{Parallelization:} Run multiple local searches simultaneously
    \item \textbf{Machine Learning:} For intelligent selection of starting points
    \item \textbf{Hybrid LS + CPLEX:} Use LS for initial solution and CPLEX for final optimization
\end{enumerate}
